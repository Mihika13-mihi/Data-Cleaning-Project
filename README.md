# Data Cleaning Project using Python and Pandas

## Project Overview
This project demonstrates the process of cleaning and preprocessing raw data using Python and the Pandas library. The dataset contained missing values and duplicate records, which were identified and handled to improve data quality and consistency.
## Objectives
- Load data from a CSV file.
- Identify missing values in the dataset.
- Replace missing numerical values with the mean value.
- Fill missing categorical values with "Unknown".
- Remove duplicate records.
- Export the cleaned dataset to a new CSV file.

## Technologies Used
- Python
- Pandas
- Visual Studio Code (VS Code)
- GitHub

## Files Included
- data.csv – Original dataset
- cleaning.py – Python script used for data cleaning
- cleaned_data.csv – Cleaned dataset generated after preprocessing

## Outcome
The project successfully transformed raw data into a clean and structured format suitable for further analysis. This project helped build practical experience in data preprocessing techniques used in real-world data analytics workflows.
